# Friendship Day Digital Gift

A production-ready, static, mobile-first interactive Friendship Day story.

## Customize
Edit `config.js`. Put your own photos in `assets/photos/` and music at
`assets/audio/song.mp3`.

## Run locally
Open `index.html` directly, or use any static server.

## Deploy
Upload the project to GitHub Pages, Netlify, or Vercel. No backend is required.

## Notes
- The photo files are intentionally placeholders; replace them with your own.
- The audio file is intentionally not included. Add a legally usable MP3 as `assets/audio/song.mp3`.
- All core interactions work with mouse, touch/pointer input, and keyboard.
- `prefers-reduced-motion` is respected.
